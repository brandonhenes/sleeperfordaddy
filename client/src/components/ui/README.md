# Edge UI Kit

Small reusable primitives for product pages. Prefer these before adding new inline card, tab, empty, loading, or row patterns.

- `PageHeader`: page title, subtitle, and optional actions.
- `Card`: standard framed section.
- `TabBar`: page-level tab navigation.
- `SegmentedControl`: compact option sets such as presets and modes.
- `LoadingSkeleton`: shared loading card.
- `ErrorState`: shared error card with optional retry action.
- `PositionBadge`: position label using shared position colors.
- `PlayerRow`: compact player summary row.
- `ResponsiveTable`: desktop table with mobile card fallback.
